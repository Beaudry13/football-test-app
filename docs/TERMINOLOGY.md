# Terminology

One action, one name, everywhere. Use football-coach words, not software
words. Don't rename a football concept casually, and don't change a term
just for variety. When a new screen needs a word, take it from here.

## Nouns

- **Rep**: capitalized as a label or tag ("REP", "Rep page") and lowercase in
  running text ("make a rep", "1 rep"). The same goes for **quiz** / **Quiz**.
  "Situational Rep" is the full name, kept where it is introduced.
- **Install** and **current install**: what the coach is installing this week.
  The current install is his choice.
- **Concept**: the coach's name for a football idea ("Motion adjustment").
  Coach screens only.
- **Player**, never athlete or user.
- **Code**: what players type to open work. Not "access code" on player
  screens.

## Player words

Players see the simplest words in PEIRA:

| Say | Not |
|---|---|
| **Next** | Continue (between questions) |
| **Check answer** / **Lock it in** | Check Answer |
| **Submit quiz** / **Finish practice** / **Finish** | Submit Quiz |
| **Review missed** | — |
| **Try the misses again** (Reps and practice only) | Retry |
| **Run the whole rep again** / **Start the whole quiz over** | Run the full practice again |
| **Done** | — |
| **Right answer** | Correct answer |
| **Not quite** | Incorrect |
| **Waiting on your coach** | Pending review |
| **Doesn't count** | Excluded from scoring |
| **Second look** | Retest |
| **The code your coach gave you** | access code |

Sentence case everywhere ("Check answer", "Quiz submitted"). Title Case
belongs only to proper names.
